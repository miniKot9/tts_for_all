## 🎙️ TTS для озвучки текста в реальном времени v0.0.1

Простой и удобный инструмент преобразования текста в речь в реальном времени, созданный для геймеров и пользователей Discord с нарушениями речи. Приложение транслирует сгенерированный голос напрямую в виртуальный микрофон, позволяя общаться в играх и голосовых чатах без задержек и необходимости использовать текстовый чат.

### Функционал

- Нейросетевой голос **Silero** (русский, английский, немецкий, испанский, французский, украинский)
- Два выхода звука: основной (для Discord) + прослушивание в динамиках
- Автозамена сокращений через `replacements.txt`
- Озвучка чисел (`10000 → десять тысяч`, `10к → десять тысяч`, `2кк → два миллиона`)
- Глобальная горячая клавиша `Ctrl+Enter` - моментально начать печатать текст, при озвучке текста `Enter` приложение автоматически возвращает последнее активное окно. Функция что бы не отвлекаться игры и общаться.
- Работает на CPU, без видеокарты

### Запуск

1. Скачать **`ttsRelese_0.0.1.zip`** 
2. Распаковать в любую папку
3. Запустить **`start.bat`**
4. При первом запуске модель Silero скачается автоматически (~50 МБ)

### Требования

- Windows 10/11 (64-bit)
- VB-Audio Virtual Cable (для передачи звука в Discord) 
- Интернет при первом запуске (для модели Silero)
